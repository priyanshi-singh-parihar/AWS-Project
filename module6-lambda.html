Module 06: AWS Lambda

⏱️ Est. Time: 40 Mins ⚙️ Services: Lambda, S3, IAM 💰 Cost: Free Tier Eligible

Core Concept & Real-World Utility

Lambda is an event-driven, serverless compute service. You provide the code, and AWS provisions the execution environment on the fly. It scales automatically from zero to thousands of concurrent executions. You pay only for the exact milliseconds your code executes, making it incredibly cost-effective for spiky workloads.

Architecture Integration

Lambda handles our asynchronous background tasks. When a student uploads a large PDF report to S3, S3 triggers a Lambda function. The function processes the PDF, extracts metadata, and updates a DynamoDB table. This totally offloads heavy processing from our main EC2 web server.

⚖️ Architecture Trade-off Analysis

Serverless Lambda vs. EC2 Worker Queues: Lambda scales instantly to zero cost when idle and requires zero server management. The trade-off is execution time limits (max 15 minutes), potential cold-start latency spikes, and lack of persistent local disk state between invocations.

Terminal / Code Execution

The `lambda_handler` is the entry point. AWS passes a massive JSON dictionary called `event` which contains all the metadata about the action that triggered the function.

import json
import urllib.parse
import boto3

def lambda_handler(event, context):
    # Digging into the nested JSON to extract the S3 Bucket and File Key
    bucket = event['Records'][0]['s3']['bucket']['name']
    key = urllib.parse.unquote_plus(event['Records'][0]['s3']['object']['key'], encoding='utf-8')
    
    print(f"Trigger received! Processing file: {key} from {bucket}")
    
    # Execution logic here...
    
    return {
        'statusCode': 200,
        'body': json.dumps('Background job completed successfully.')
    }

Debugging & Troubleshooting

Error: Task timed out after 3.00 seconds.
If your CloudWatch logs show this error, your function ran out of time before completing its execution. Either your code is stuck in an infinite loop, an external API is responding slowly, or you simply need to go to Configuration > General configuration and increase the Timeout value.
