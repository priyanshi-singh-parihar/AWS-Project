Module 08: Elastic Load Balancing

⏱️ Est. Time: 45 Mins ⚙️ Services: ALB, Target Groups, EC2 💰 Cost: Free Tier Eligible

Core Concept & Real-World Utility

Elastic Load Balancing evenly distributes incoming network traffic across a fleet of targets (EC2 instances, containers, or IP addresses). It increases application availability and fault tolerance. Application Load Balancers (ALB) operate at Layer 7 (HTTP/HTTPS), allowing advanced path-based routing and SSL termination.

Architecture Integration

Users hit the ALB, not the EC2 instances. The ALB holds our SSL certificate (HTTPS), decrypts the secure traffic, inspects the URL path, and forwards plain HTTP traffic to our internal EC2 instances. This shields our servers from direct internet exposure and centralizes our encryption management.

⚖️ Architecture Trade-off Analysis

ALB Protection vs. Direct EC2 Access: Using an Application Load Balancer provides automatic SSL encryption, health checks, and shields backend servers from direct cyber-attacks. The trade-off is a small fixed hourly infrastructure cost and milliseconds of extra network latency.

Terminal / Code Execution

When an ALB intercepts traffic, it obscures the client's original IP address. Backend code must extract the client IP from the `X-Forwarded-For` HTTP header injected by the load balancer.

# Python/FastAPI implementation behind an ALB

from fastapi import FastAPI, Request

app = FastAPI()

@app.get("/")
def read_root(request: Request):
    # Extract the original user IP injected by the ALB
    client_ip = request.headers.get("x-forwarded-for")
    
    # Fallback if accessed directly (bypassing ALB)
    if not client_ip:
        client_ip = request.client.host
        
    return {"message": "Success", "client_ip": client_ip}

Debugging & Troubleshooting

Error: 502 Bad Gateway / Targets Unhealthy.
If the ALB returns a 502 error, it cannot communicate with the backend EC2 instances. Go to Target Groups. If the instances are marked 'Unhealthy', the ALB health check ping is failing. Ensure the EC2 web service (Nginx/Apache) is running and the EC2 Security Group allows traffic from the ALB.
