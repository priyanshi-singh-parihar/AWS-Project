Module 09: Auto Scaling Groups

⏱️ Est. Time: 60 Mins ⚙️ Services: ASG, Launch Templates, EC2 💰 Cost: Free Tier Eligible

Core Concept & Real-World Utility

Auto Scaling Groups (ASG) provide dynamic capacity management. They automatically scale out (add instances) during traffic spikes and scale in (remove instances) when demand drops, optimizing both performance and cost. ASGs also enforce self-healing by replacing degraded instances automatically.

Architecture Integration

We attached an ASG directly to our Application Load Balancer's Target Group. During university exam results day, when traffic spikes 500%, CloudWatch detects the high CPU usage and the ASG automatically provisions new web servers, registers them with the ALB, and handles the load seamlessly.

⚖️ Architecture Trade-off Analysis

Auto Scaling Elasticity vs. Boot Latency: ASGs ensure your application never crashes under sudden traffic surges and saves money when idle. The trade-off is boot latency—new instances take 2-3 minutes to spin up, meaning sudden massive flash-crowd spikes can temporarily overwhelm existing servers before scaling completes.

Terminal / Code Execution

The User Data script in a Launch Template is absolutely critical. An auto-scaled instance must be 100% self-configuring on boot, requiring zero manual human SSH intervention.

#!/bin/bash
# High-fidelity User Data script for ASG instances
apt-get update -y
apt-get install -y nginx git python3-pip

# Clone application code
git clone https://github.com/itm-project/backend.git /var/www/html/app
cd /var/www/html/app

# Install dependencies and restart service
pip3 install -r requirements.txt
systemctl restart nginx

Debugging & Troubleshooting

Error: Instances are constantly terminating and relaunching (Flapping).
If instances are stuck in a create/terminate loop, your ELB health check is failing. The ASG launches the instance, the ALB pings `/health`, but because your User Data script hasn't finished running yet (or failed entirely), the ALB marks it Unhealthy and the ASG kills it. Increase the Health Check Grace Period.
